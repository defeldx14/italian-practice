# Parole — phone app

Upload **the contents of this folder** to your GitHub repository root. index.html must sit at the repository root, alongside app.js, style.css, shared/ and icons/. Enable GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).

Open the resulting Pages URL in iPhone Safari → Share → Add to Home Screen. Open the installed app online once; Sync & backup reports when its offline app shell is ready.

No build or dependencies. No example vocabulary is preloaded. Import a versioned JSON backup from Italian Hover or configure optional Drive sync. A public web OAuth client ID can be entered in the app or config.js. Never upload vocabulary exports, client secrets or token files to GitHub.

The complete package includes ITALIAN-README.md and SYNC-SETUP.md with installation, Google OAuth configuration, scheduling, conflict behavior and limitations. Real Google OAuth needs your setup; mocked tests are not live sync validation.
