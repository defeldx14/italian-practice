Your words stay yours.

Vocabulary, original sentences, optional translations, source links/titles, review events and deletion history are stored in IndexedDB on your device. No analytics, advertising, account server or vocabulary is included in the public GitHub repository.

Google account and automatic saving

On the web, Google is the only sign-in provider. The app requests openid and email to obtain your stable account ID and email directly from Google. That ID separates local account profiles; the email labels the selected profile. They are stored locally, not in the public repository. Browser profiles are not encrypted against someone using an unlocked device.

Connecting Google grants access only to this application's hidden appDataFolder, using drive.appdata. Automatic sync sends vocabulary and review history to your chosen Google account after changes, when the app regains focus or connectivity, and periodically while visible. Expired authorization requires reconnecting Google. Earlier unlinked device data is not merged unless you explicitly add it to the connected account. A snapshot named italian-vocabulary-v1.json plus immutable JSON journal batches preserves simultaneous edits. Both OAuth clients must belong to one Cloud project. No sharing permission is requested.

Tokens stay in memory on the web and in Chrome's identity token cache for the extension. They are not stored in vocabulary backups or source. Public OAuth client IDs may be stored in settings. Google's policies apply to Google authentication, Drive and translations. Disconnect stops this client's sync access; it does not erase remote data or revoke all other clients. You can remove app access through your Google account and remove hidden application data through Drive settings.

Translation and deletion

The Chrome extension sends hovered words to an unofficial Google Translate endpoint, and sends a bounded sentence only when you request its translation. Google receives your IP and the request text. No paid translation is used. In the practice app, answering a sentence quiz requests an English translation of the saved Italian sentence if it is missing. Only that sentence is sent to the same unofficial Google Translate endpoint; it is saved locally and included in your configured sync. My words also offers an explicit Translate sentence button. Translations are not requested before revealing the quiz answer. Failed requests leave your vocabulary saved and can be retried.

Deleting an entry creates a tombstone, hiding it from practice. Old text remains in history, backups and sync journals to prevent data loss and resurrection. This is not a secure erasure function. To erase all copies, export anything you want to keep, clear site/extension data, remove the app's hidden Drive data and delete backups; stop all other devices first.

Storage

Offline use requires an initial successful online load. iOS/browser storage can be evicted or cleared; export backups regularly. Application data is not encrypted by this app. Users with access to your device or Google account may access it. A GitHub Pages origin can host multiple repositories: only host trusted code on the same origin. Site storage is shared at the origin level.

This is a personal app. Review its README before distributing it, including OAuth verification and policy requirements. No secret API key or client secret is required.
